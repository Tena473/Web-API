# Run Project:

1. cd vue-angkham

- ເປີດ Termainal ໃຫມ່
2. npm run dev (Run ໜ້າບ້ານ ແລະ ຫຼັງບ້ານ)

- ເປີດ Termainal ໃຫມ່ 
3. npm run nodemon_server (Run ລະບົບອັບໂຫລດຮູບຫຼັງບ້ານ)

- ເປີດ Termainal ໃຫມ່ 
4. npm run DB (Run ລະບົບ CRUD ຫຼັງບ້ານ)


ສາມາດແກ້ port ຢູ່ vite.confing
